# GrapheneOS virtual-device patch inventory

Keep every downstream change required for the CarbonHV ARM64 virtual device here as an auditable patch series or repo-project overlay. The release manifest must record patch IDs and upstream bases.

Expected patch areas are the virtual product definition, virtio graphics/HWC/gralloc selection, virtual audio/input/power integration, guest-agent service policy, updater endpoint ownership, and security-feature accounting. Do not copy Pixel vendor firmware or present virtual software keys as hardware-backed StrongBox keys.
